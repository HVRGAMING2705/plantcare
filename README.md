# PlantCare - Plant Watering Reminder App

A fully functional plant care app that allows users to track plants, set watering schedules, and get reminders. A working plant app with plant tracking, watering reminders, and care history.

## Features

- Add plants with name and watering frequency
- Watering schedule and due reminders
- Plant care history log

## Modules

- `plantcare_plant_watering_reminder_app`: add_plants_with_name_and_watering_frequency, watering_schedule_and_due_reminders, plant_care_history_log

## Tech Stack

React, Tailwind CSS, localStorage
